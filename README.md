# General Information
- Movin' Music intends to enhance the experience of listening to music by making album covers animated and interactive
- I undertook this project as I love listening to music, and I find album covers interesting and exciting. I love to think about how album covers relate to the songs, and I find that a good album cover often makes the album even better. I thought this could be even further enhanced through movement.

# Technologies Used
- Processing

# Features
- Continuously moving elements
- Elements that respond visually to being clicked
- Elements that respond sonically to being clicked

# Setup
- The project requires the Processing app/software to be installed
- The project requires the Processing Sound Library to be installed

# Usage
- The moving elements are mostly activated by being clicked on.
- This is controlled through multiple lines of code, notably the code featured within the void mousePressed() command.
